# NFC 디지털 명함 솔루션

> 📣 **SNS 자동화**: 인스타그램·샤오홍슈·네이버블로그용 콘텐츠를 자동 생성·업로드하는
> 시스템은 [`social-automation/`](social-automation/README.md) 에 있습니다.
>
> 🎓 **수료증 자동 생성기**: 엑셀 명단으로 학생별 수료증 PNG 를 만드는 도구는
> [`certificate.html`](certificate.html) 입니다. 자세한 사용법은 아래 [수료증 자동 생성기](#수료증-자동-생성기) 참고.

폰을 NFC 태그에 대면 명함 정보(사진·소속·성명·직책·연락처·이메일)가 상대방 연락처로 전달되는 솔루션입니다.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 웹 명함 페이지. NFC 태그의 URL로 열리며 "연락처에 저장" 버튼으로 사진 포함 vCard(.vcf)를 전달 |
| `nfc-writer.html` | NFC 태그 기록 도구 (Android Chrome, Web NFC 사용) |

## 동작 원리 (중요)

NFC는 카메라 촬영이 아니라 **태그에 폰을 갖다 대는(태깅)** 방식입니다.
상대방이 별도 앱 없이 폰을 태그에 대기만 하면 됩니다.

- **Android**: NFC 켜져 있으면 탭 즉시 반응
- **iPhone XS 이상**: 백그라운드 NFC 읽기 지원 — 잠금화면에서도 태그를 대면 알림이 뜸

## 두 가지 방식

### 방식 A — URL 방식 (권장, 사진 포함 가능)

1. `index.html` 상단의 `CARD` 객체에 본인 정보 입력, 같은 폴더에 `photo.jpg`(프로필 사진, 200~400px 권장) 배치
2. HTTPS 호스팅에 업로드 — GitHub Pages / Vercel / Netlify 모두 무료로 가능
3. `nfc-writer.html`을 같은 호스팅에 올린 뒤 **Android Chrome**에서 열기
4. "URL 방식" 탭에 명함 페이지 주소 입력 → 기록 버튼 → 태그에 폰 대기
5. 완료. 이후 누구든 태그에 폰을 대면 명함 페이지가 열리고, 버튼 한 번으로 사진 포함 연락처가 저장됨

- 태그: 저렴한 **NTAG213**(144B)으로 충분 (URL만 저장하므로)
- 사람마다 정보가 다르면 URL을 `card.example.com/hong`, `card.example.com/kim`처럼 나누거나, `index.html`을 쿼리스트링(`?name=...`) 기반으로 확장

### 방식 B — vCard 직접 기록 (사진 불가, 탭 즉시 연락처 추가)

`nfc-writer.html`의 "vCard 직접 기록" 탭 사용.
태그를 탭하면 Android에서 바로 연락처 추가 화면이 뜹니다.

- 텍스트만으로 200~300바이트 → **NTAG215(504B) 또는 NTAG216(888B)** 필요
- **사진은 용량상 불가** (사진 base64는 수십 KB)
- iPhone은 vCard NDEF 태그를 OS에서 직접 처리하지 않는 경우가 많음 → 아이폰 대응이 필요하면 방식 A 사용

## PC에서 태그 기록 (선택)

USB NFC 리더(ACR122U 등)가 있다면 Python으로도 기록할 수 있습니다:

```bash
pip install nfcpy ndeflib
```

```python
import nfc, ndef

URL = "https://card.example.com/hong"

def write(tag):
    if tag.ndef:
        tag.ndef.records = [ndef.UriRecord(URL)]
        print("기록 완료:", URL)
    return True

with nfc.ContactlessFrontend("usb") as clf:
    print("태그를 리더에 올려놓으세요…")
    clf.connect(rdwr={"on-connect": write})
```

vCard를 직접 기록하려면:

```python
vcf = (
    "BEGIN:VCARD\r\nVERSION:3.0\r\n"
    "N;CHARSET=UTF-8:홍길동;;;;\r\nFN;CHARSET=UTF-8:홍길동\r\n"
    "ORG;CHARSET=UTF-8:㈜디에이블\r\nTITLE;CHARSET=UTF-8:대표이사\r\n"
    "TEL;TYPE=CELL:010-0000-0000\r\nEMAIL:hello@example.com\r\n"
    "END:VCARD"
)
record = ndef.Record("text/vcard", "", vcf.encode("utf-8"))
# tag.ndef.records = [record]
```

## 태그 구매 시 체크리스트

- 칩: NTAG213 / 215 / 216 (NDEF 표준, iOS·Android 모두 호환)
- 형태: 카드형(명함 크기), 스티커형, 에폭시 키링 등
- 금속 표면에 붙일 경우 "on-metal(안티메탈)" 타입 필요

## 자주 겪는 문제

- **iPhone에서 반응 없음** → iPhone X 이하는 백그라운드 읽기 미지원. URL 방식 + iPhone XS 이상이면 정상 동작
- **Web NFC 버튼이 안 눌림** → iOS/데스크톱 Chrome은 Web NFC 미지원. 반드시 Android Chrome + HTTPS
- **.vcf 다운로드 후 아무 일 없음(Android 일부 기기)** → 알림창의 다운로드 파일을 탭하면 연락처 앱이 열림
- **태그 기록 실패** → 태그가 잠금(read-only) 상태이거나 용량 초과. 새 태그로 시도

# 수료증 자동 생성기

`certificate.html` — 엑셀 명단을 올리면 **학생마다 수료증 PNG 를 자동으로 만들어 내 PC 에 저장**하는 도구입니다.

- 서버 없음. 파일 하나(HTML)만으로 브라우저 안에서 전부 처리합니다.
- 로그인·설치·계정 불필요. 링크만 알면 내부 직원 누구나 씁니다.
- 명단 파일과 이미지는 **어디로도 전송되지 않습니다.**

## 여는 방법

| 방법 | 주소 / 절차 |
|---|---|
| 웹에서 열기 | GitHub Pages 배포 주소 뒤에 `/certificate.html` (예: `https://<계정>.github.io/namecard/certificate.html`) |
| 파일로 쓰기 | `certificate.html` 을 내려받아 더블클릭 (인터넷이 없어도 동작. 손글씨 글꼴만 기본 글꼴로 대체됨) |

## 사용 순서

1. **엑셀 올리기** — `.xlsx` `.xls` `.csv` 지원. 첫 행이 제목 행이어야 합니다.
   - 제목이 `학교명 / 학생이름 / 프로그램명 / 수료증 발행일` 이면 자동으로 인식합니다.
     (`학교`, `성명`, `과정명`, `수료일` 처럼 비슷한 이름도 인식하며, 못 찾으면 [열 연결]에서 직접 고르면 됩니다)
   - 상단 **[샘플 엑셀 양식 내려받기]** 버튼으로 표준 양식을 받을 수 있습니다. (시행기관 열이 포함된 예시)
   - 엑셀 날짜 셀·문자열(`2026.08.24`, `2026-08-24`, `20260824`) 모두 인식하고, 한글이 깨진 EUC-KR CSV 도 자동으로 처리합니다.
2. **공통 설정** (필요할 때만) — 시행기관·본문 문구·대표자명·로고·직인·글꼴·해상도·파일명 규칙을 바꿀 수 있습니다. 설정은 그 브라우저에 자동 저장됩니다.
3. **저장**
   - **[선택 학생 ZIP으로 저장]** — 전체를 ZIP 한 개로 (권장)
   - **[선택 학생 PNG 개별 저장]** — 파일을 하나씩 내려받기
   - 표의 **[PNG]** 버튼 — 그 학생 한 명만 저장

명단 표의 칸은 눌러서 바로 고칠 수 있고, 체크박스로 저장할 학생을 고를 수 있습니다.

## 만들어지는 파일

- 형식: PNG (기본 2배 해상도 **2246 × 1588**, 1배·3배 선택 가능)
- 이름: `{학교}_{이름}_수료증.png` (규칙 변경 가능, 같은 이름이 겹치면 `_2` 가 붙습니다)

## 문구 치환값

본문·발급기관·파일명 칸에 아래 값을 넣으면 학생마다 자동으로 바뀝니다.

| 치환값 | 내용 |
|---|---|
| `{이름}` | 학생이름 |
| `{학교}` | 학교명 |
| `{과정}` | 프로그램명 |
| `{기관}` | 시행기관 (엑셀에 열이 없으면 공통 설정값, 등록된 기관과 맞으면 그 기관의 표기) |
| `{날짜}` | 발행일 |

기본 문구는 아래와 같습니다.

```
위 학생은 {기관}에서 실시하는
“{과정}” 과정을 수료하였기에 이 증서를 수여합니다.
```

## 여러 교육청(기관) 함께 쓰기

기관마다 **로고 · 시행기관 문구 · 프로그램명 강조색**이 다르므로, 이를 한 묶음(`기관`)으로 저장해 두고 골라 씁니다.

기본으로 두 곳이 들어 있습니다.

| 기관 | 시행기관 문구 | 로고 | 프로그램명 |
|---|---|---|---|
| 인천광역시교육청 | 인천광역시교육청 | 내장 | 검정 |
| 충청북도교육청 | 충청북도 교육청 | 내장 | 초록 강조 |

두 곳은 아무 설정 없이 바로 쓸 수 있습니다. 다른 교육청은 아래처럼 한 번만 등록하면 됩니다.

### 새 기관 등록 (한 번만)

1. [공통 설정] → **발급 기관** 에서 **[＋ 새 기관]** 으로 이름 만들기
2. **시행기관** 문구, **로고 이미지**(배경 투명 PNG 권장), **프로그램명 색** 을 채우기
3. **[현재 설정 저장]** 클릭 → 그 기관에 저장됩니다

### 명단 하나에 여러 교육청이 섞여 있을 때

엑셀에 **`시행기관`** 열을 넣으면 학생마다 로고·기관명·강조색이 자동으로 바뀝니다.
(띄어쓰기는 무시하고 맞춰 보므로 `충청북도교육청` / `충청북도 교육청` 둘 다 인식합니다)

| 학교명 | 학생이름 | 프로그램명 | 수료증 발행일 | 시행기관 |
|---|---|---|---|---|
| 디플랜드초등학교 | 김보희 | 스마트 3in1 건강교실 | 2026.08.24 | 인천광역시교육청 |
| 에이비초등학교 | 김혜미 | 스마트! 더 건강한 챌린지 교실 | 2026.06.17 | 충청북도교육청 |

자동 전환을 끄고 화면에서 고른 기관 하나로만 발급하려면 **[명단의 시행기관에 맞춰 … 자동 전환]** 체크를 해제하세요.

### 다른 직원에게 기관 설정 나눠 주기

기관 설정은 등록한 사람의 브라우저에만 저장됩니다.
**[기관 목록 내보내기]** 로 받은 `수료증_기관목록.json` 을 사내에 공유하고, 각자 **[불러오기]** 로 넣으면 로고까지 그대로 옮겨집니다.

## 그 밖의 커스터마이즈

- **발급기관 문구**: 공통 설정에서 바로 수정 (기본 `(주) 디에이블`, 오른쪽 아래 날인 왼쪽에 표시)
- 하단 줄(로고 · 발행일 · 발급기관 · 날인)은 모두 같은 가로선에 맞춰 그립니다
- **직인**: 이미지 교체 또는 제거 가능
- 도안(배경·테두리·`Certificate` 제목·워터마크)과 기본 로고·직인은 파일 안에 이미지로 들어 있어, 인터넷이 없어도 그대로 나옵니다.
- 로고 원본은 `assets/` 에 함께 보관합니다.

## 기술 메모

- 도안은 원본 수료증에서 가변 텍스트만 지운 배경 이미지이며, 그 위에 캔버스로 글자를 그립니다. 위치·크기는 원본과 픽셀 단위로 맞췄습니다.
- 글꼴: 학생 이름은 Google Fonts 손글씨체(나눔 붓글씨·펜글씨·개구·명조 중 선택), 본문은 Noto Sans KR. 인터넷이 막혀 있으면 시스템 기본 글꼴로 대체되고 안내 문구가 표시됩니다.
- 한글 웹글꼴은 수십 개 조각으로 나뉘어 배포되므로, 그릴 글자를 먼저 내려받은 뒤(`document.fonts.load(글꼴, 글자)`) 캔버스에 그립니다. 이 과정을 건너뛰면 이름 안에서 글자마다 글꼴이 달라집니다. 글꼴에 아예 없는 글자가 섞이면 해당 이름 전체를 고딕으로 통일하고 안내를 띄웁니다.
- 내장 라이브러리: [SheetJS](https://sheetjs.com) 0.18.5 (Apache-2.0) — 엑셀 읽기/쓰기, [JSZip](https://stuk.github.io/jszip/) 3.10.1 (MIT) — ZIP 묶기. 두 라이브러리는 HTML 안에 포함되어 있어 인터넷 없이도 동작합니다.
