📸 인스타그램 연동 도우미

아래 값들은 이 브라우저 안에서만 사용되고 어디에도 저장·전송되지 않습니다 (Meta 서버와 직접 통신).

1 Meta 개발자 앱 만들기 (최초 1회)

  1. developers.facebook.com 접속 → 우측 상단 로그인 (페이스북 계정) → 처음이면 개발자 등록 동의
  2. 우측 상단 내 앱 → 앱 만들기
  3. 사용 사례 선택 화면: "기타(Other)" 선택 → 다음
  4. 앱 유형: "비즈니스(Business)" 선택 → 다음
  5. 앱 이름: sns-studio (아무거나) → 앱 만들기
  6. 만든 앱 화면에서 좌측 앱 설정 → 기본 설정 → 앱 ID 와 앱 시크릿 코드(표시 버튼 클릭)를 복사해 두기

2 임시 토큰 발급 (Graph API 탐색기)

  1. developers.facebook.com/tools/explorer 접속
  2. 우측 Meta 앱: 방금 만든 앱 선택
  3. 사용자 또는 페이지: 사용자 토큰 선택
  4. 권한 추가에서 아래 4개를 검색해 추가:
    instagram_basic instagram_content_publish pages_show_list business_management
  5. Generate Access Token 클릭 → 페이스북 로그인 창에서 진행 — 중간에 인스타그램 계정 선택과 페이지 선택 화면이 나오면 모두 선택 (페이지·인스타 연결이 안 되어 있으면 이 과정에서 연결됩니다)
  6. 완료되면 액세스 토큰 칸에 생긴 긴 문자열(EAA...)을 복사

3 여기에 붙여넣고 변환

앱 시크릿 코드를 확인할 수 없다면 (비밀번호 확인이 안 되는 경우): ① 토큰 디버거에 2번 토큰을 붙여넣고 디버그 → 하단의 "액세스 토큰 연장" 버튼 클릭 → 연장된 토큰을 복사. ② 아래에서 앱 ID·시크릿은 비워 두고, 연장된 토큰만 세 번째 칸에 넣고 변환하세요.
IG_USER_ID (인스타그램 계정 번호)
IG_ACCESS_TOKEN (장기 토큰 · 약 60일 유효)
⚠️ 이 토큰은 비밀번호처럼 다루세요. 약 60일 뒤 만료되며, 만료 시 2~3번만 다시 하면 됩니다.

4 GitHub에 등록 (자동 발행 켜기)

  1. github.com 로그인 (healivesoh-ctrl 계정)
  2. 시크릿 등록 페이지 열기 → Name: IG_USER_ID, Secret: 위의 계정 번호 → Add secret
  3. 같은 페이지에서 한 번 더 → Name: IG_ACCESS_TOKEN, Secret: 위의 장기 토큰 → Add secret
  4. 끝! 이제 스튜디오에서 ✅ 자동 발행 승인한 콘텐츠가 매일 1건씩 인스타그램에 자동 게시됩니다.
